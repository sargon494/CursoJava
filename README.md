# Curso de Java

Curso personal para repasar Java desde los fundamentos y practicar con el temario de Programación de DAM.

## Usar el curso

Abre `index.html` en un navegador moderno. Para servirlo localmente desde la carpeta del proyecto:

```powershell
python -m http.server 8000
```

Después visita `http://localhost:8000`.

El curso no necesita dependencias ni un proceso de compilación. El progreso de ejercicios y las respuestas de las autoevaluaciones se guardan en el almacenamiento local del navegador.

## Método de estudio

1. Lee la explicación y reproduce los ejemplos.
2. Resuelve los ejercicios en Eclipse, sin copiar la solución.
3. Prueba entradas normales, límites y casos inválidos.
4. Cuando termines, abre la solución y lee debajo la explicación para entender las decisiones del código.
5. Marca los ejercicios terminados y completa la autoevaluación.
6. Usa los exámenes para practicar problemas que combinan varias unidades.

Las soluciones disponibles son material de revisión: intenta resolver primero el ejercicio y compara después tu enfoque con la propuesta.

## Contenido

El recorrido está ordenado en 15 unidades, desde la introducción a Java hasta JDBC, e incluye ejercicios, exámenes y una sección de referencia rápida.
